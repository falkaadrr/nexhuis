⚙️ Setup Firebase

Untuk sync real-time antar device, hubungkan ke Firebase Realtime Database (gratis).

1

Buat Project Firebase

Buka console.firebase.google.com → Add project → beri nama (misal: rpm-assets).

2

Aktifkan Realtime Database

Build → Realtime Database → Create → region asia-southeast1 → Start in test mode.

3

Set Rules

Realtime Database → Rules → paste → Publish:

{"rules":{".read":true,".write":true}}
4

Salin firebaseConfig

Project Settings ⚙️ → General → Your apps → Web app → Register → copy config.
